  - The list of methods becomes 5; add "Multiple imputation followed by LSPIM (MI-LSPIM)".

- **MSE section (linear only; Classical ML, MI + closed form, Reweighting).** Rename to e.g.
  "MSE, bias² and variance of beta3".
  - Compute bias² = (mean(beta3_hat) − beta3)² and variance = mean((beta3_hat − mean(beta3_hat))²)
    per method × scenario from the per-replicate `estimate_beta3` in run 60bac5f5db60632f's
    scenario files, over all replicates with `convergence_status != "error"` (same set as MSE).
    Variance has denominator R, so bias² + variance = MSE exactly. Checked on 2026-10-30: the
    difference from the stored `mse_beta3` is below 3e-17 in every scenario.
  - **Tables:** one combined table per dropout mechanism (HM table, 3O table). Rows n × method
    (15 rows). Columns beta3 = 0.22 / 0.035 / 0, each split into MSE, bias², var (9 value
    columns). All three metrics in **scientific notation with 3 significant digits** (e.g.
    `1.35e-01`).
  - **Figures:** dot-and-line plots in the existing `metric_plot()` style: MSE (the existing
    figure), bias² on a log y-axis, variance on a linear y-axis.
  - **No violin plots** (the user dropped them).
  - Bias² ranges about 1e-10 to 8e-4, so variance makes up essentially all of the MSE. Most bias² is
    Monte Carlo noise (MCSE of the bias about 0.005 at n = 10, so bias² about 3e-5 from noise alone).
    The exception is MI + closed form at n = 10, beta3 = 0.22, HM: bias about 0.028, roughly 5 MCSE.
    Say this in the bullets and check the 3O numbers.
